# 街头唱歌点歌微信小程序

这是一个不用登录即可使用的微信小程序示例，适合街头演唱时给观众扫码点歌。

## 功能

- 观众浏览你提前准备好的歌单并点歌
- 按歌名、歌手、标签搜索并点歌
- 查看当前设备里的点歌队列，支持标记未唱、正在播放、已唱和删除
- 歌单里没有的歌可以提交“建议添加”
- 观众可以匿名留言
- 点歌、建议和留言都会保存在当前小程序缓存中

## 使用方式

1. 打开微信开发者工具。
2. 导入本目录 `street-song-request-miniprogram`。
3. AppID 可以先选择测试号，或把 `project.config.json` 里的 `appid` 换成你自己的小程序 AppID。
4. 在 `data/songs.js` 里修改成你自己的歌单。
5. 预览或上传体验版后，用微信开发者工具生成二维码，观众扫码即可进入。

## 说明

当前版本是纯前端本地缓存版，适合先体验流程。正式演出时，如果需要所有观众提交到同一个实时点歌队列，建议接入微信云开发数据库，把 `utils/storage.js` 替换为云数据库读写。

微信小程序不能读取真实设备 MAC 地址。当前版本会为当前手机生成一个本地设备码，用来保持匿名留言身份一致。
